# ClippyOffline — v5.0.0 stable

Локальный настольный персонаж для Windows 11 на C# / WPF. Не использует AI-сервисы, сеть, содержимое документов и буфер обмена. Не записывает и не перехватывает ввод с клавиатуры; состояние клавиш опрашивается только для назначенных горячих клавиш (см. раздел «Какие системные данные использует приложение»).

## Что нового в 5.0.0

- Размеры скрепки в меню трея совпадают с настройками (60–200%).
- У каждой фразы есть своё поле звука (обзор, очистка, громкость) и кнопка «Сбросить» для возврата только этой фразы к стандартной. Звук фразы играет вместо звука состояния, если задан.
- Горячие клавиши на «Показать / спрятать» и «Сон / пробуждение» (раздел «Поведение»): одна клавиша или сочетание, например Ctrl+Home. Одно и то же сочетание включает и выключает функцию, клавиши продолжают работать в других программах, но не в полноэкранных. Не назначай на горячую клавишу одиночную букву, цифру или другую клавишу, которой ты печатаешь: она будет срабатывать при наборе текста в любой программе. Лучше использовать сочетание с Ctrl/Alt/Shift или редко используемую клавишу. Горячие клавиши не работают в полноэкранных приложениях (игры, видео, презентации) — там они игнорируются.
- Галочка «Горячая клавиша сна работает и при спрятанной скрепке»: скрепка засыпает не показываясь и появляется уже спящей.

## Что нового в 4.1.0

- В режиме сна скрепку можно перемещать курсором (по умолчанию включено); отключается галочкой «Разрешить перемещать скрепку курсором в режиме сна».
- Настройка всех фраз: раздел «Фразы» в окне настроек, группы раскрываются стрелкой, у каждой фразы есть «Сохранить» и «Очистить», можно добавить свою фразу или вернуть стандартные. Изменения хранятся в `settings.json`.
- Тонкие ползунки громкости и число громкости рядом с каждым.
- Отдельное состояние звука «Раскрытие» (раньше при показе скрепки играл звук пробуждения).
- Галочка «Звуки сна и пробуждения, если скрепка уснула сама от бездействия».
- Галочки в настройках реагируют только на сам квадрат и подпись.

## Сборка
ЭТО ДЛЯ ТЕХ, КТО СКАЧАЛ ИСХОДНИКИ, А НЕ РЕЛИЗ!!!


Требуется .NET 8 SDK для Windows. Открой PowerShell в папке с `ClippyOffline.csproj` и выполни:

```powershell
dotnet restore --ignore-failed-sources
dotnet build -c Release
dotnet run -c Release
```

Чтобы получить автономный EXE для Windows x64 (без установленного .NET у пользователя):

```powershell
dotnet publish -c Release -r win-x64 --self-contained true /p:PublishSingleFile=true
```

Готовая папка будет в `bin\Release\net8.0-windows\win-x64\publish`. Только она нужна для запуска и раздачи: `ClippyOffline.exe` из неё, рядом с ним папка `Assets` и несколько служебных `.dll`. Папку целиком можно копировать куда угодно и запускать автономно. Остальные `ClippyOffline.exe` в `bin\Release\...` (в `net8.0-windows` и в `win-x64`) — промежуточные результаты сборки, их не используют отдельно.

## Установщик

В корне проекта лежат `build.ps1` и папка `installer` (скрипт Inno Setup 6.3 или новее). Запусти `build.ps1` в PowerShell: он сам сделает publish в `dist\app` и соберёт установщик `installer\Output\ClippyOffline-Setup-5.0.0.exe`. Если Inno Setup не найден, останется готовая папка `dist\app`.

Установщик: выбор папки, ярлык в меню «Пуск», по желанию ярлык на рабочем столе и автозапуск, запуск после установки, удаление через «Приложения» с вопросом об удалении настроек. По умолчанию ставится для текущего пользователя без прав администратора, в окне можно выбрать установку для всех.

## Управление

- Левый клик по персонажу — реплика.
- Быстрое перемещение курсора при зажатой левой кнопке — перетаскивание. Простое нажатие не запускает системный `DragMove`, поэтому окно не должно подвисать на коротких кликах.
- Серия кликов: 1-й клик обычный, 2-й «двойной», 3-й и 4-й обычные, 5-й запускает реакцию `ALERT` (злость). Если не кликать около минуты, счётчик сбрасывается.
- Если скрепку спрятали вручную, она сама не появляется после полноэкранных окон, вернуть её можно через трей.
- Правый клик по персонажу или облачку открывает контекстное меню.
- Меню в системном трее содержит настройки, сон, размер персонажа, звуки, автозапуск и выход.
- Ручной сон сохраняется, пока его явно не отключить кнопкой «Режим сна» в трее/контекстном меню. Обычные клики персонажа не выводят его из ручного сна.
- Автоматический сон срабатывает после 300 секунд без системного ввода.
- Полноэкранные окна скрывают персонажа немедленно, чтобы анимация не поверх игры.
- «Спрятаться» проигрывает анимацию `HIDE`; «Выход» проигрывает `GOODBYE` (велосипед уезжает, бумажка сворачивается) и сразу закрывает приложение.

## Настройки

Настройки сохраняются в `%LOCALAPPDATA%\ClippyOffline-by-Chayniy_Alkash\settings.json`.

В диалоге настроек видна картинка скрепки, можно включить тёмную тему или ретро-тему Windows XP (она применяется к окну настроек, меню скрепки, меню в трее и облачку; цвет заголовка окна меняется на синий XP только в Windows 11), можно независимо менять размер скрепки и облачка и назначать собственные WAV-файлы для запуска, клика, двойного клика, спама/злости, смены приложения, фоновой реплики, сна, пробуждения, скрытия и выхода. Если для состояния не выбран файл, звука не будет: системные звуки Windows не используются. Звуки по умолчанию выключены.

Автозапуск записывается только в `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`, то есть для текущего пользователя, без необходимости в правах администратора.

## Анимации

В комплекте 43 локальных анимационных набора. Повседневные/жестовые анимации выбираются как редкие фоновые реакции; `GREETING`, `SHOW`, `HIDE`, `GOODBYE`, `ALERT` и `IDLESNOOZE` назначены на соответствующие состояния. Частота фоновых реплик намеренно снижена.

## Безопасность и ограничения

- Приложение не выполняет сетевых запросов и не содержит телеметрии.
- Для реакции на смену активного приложения считываются имя процесса и HWND активного окна; содержимое окон не читается.
- Для определения бездействия используется Windows `GetLastInputInfo`.
- Кастомные звуки загружаются с локального диска. Используй WAV-файлы из источников, которым доверяешь.
- Запускай приложение без повышения прав. Не размещай его в папке, доступной на запись недоверенным пользователям.
- Сборка в среде разработки автора не подтверждена, так как в ней отсутствует .NET SDK. Если локальная сборка выдаёт ошибку, пришли полный текст.

## Какие системные данные использует приложение

Только то, что нужно для поведения персонажа: дескриптор, класс и размеры окна, которое сейчас на переднем плане (чтобы спрятаться при полноэкранном приложении и не прятаться из-за рабочего стола или трея), и время бездействия пользователя (для режима сна). Если назначена хотя бы одна горячая клавиша, приложение каждые 25 мс опрашивает через `GetAsyncKeyState` состояние только этой клавиши и модификаторов Ctrl/Alt/Shift/Win (в том числе во время работы других программ; в полноэкранных приложениях срабатывание игнорируется). Если горячие клавиши не назначены, опрос не запускается. Нажатия не записываются, не сохраняются и не отправляются, текст по ним восстановить нельзя, клавиши не блокируются и не подменяются. Горячей клавишей можно назначить и кнопку мыши — тогда так же опрашивается состояние только этой кнопки. Приложение не читает содержимое экрана и координаты кликов за пределами своего окна, не ставит глобальных хуков (`SetWindowsHookEx`, `RegisterHotKey`) и не содержит сетевого кода.
